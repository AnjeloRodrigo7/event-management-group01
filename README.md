# UniConnect Events

Collaborative website project for CSC1153: Collaborative Website Development Using Git and GitHub.

## Project

UniConnect Events is a responsive university event management website. Students can discover upcoming events, learn about the project, and register their interest.

## Pages

- `index.html` — home page and featured events
- `about.html` — purpose and values
- `events.html` — upcoming event calendar
- `contact.html` — registration and contact form
- `styles.css` — shared responsive styling
